# Améa HQ
Upload all files to the root of your GitHub repository and enable GitHub Pages. On iPhone, open the live site in Safari → Share → Add to Home Screen.

This version works as an installable private prototype and stores its data in that browser/device. Settings includes JSON backup export. Real cloud sync, background push notifications, silent iOS Calendar insertion, automatic website order sync, and automated email/WhatsApp receipt delivery need a backend/integration before using this as the sole store of real customer data. Never put private API keys in a public GitHub repository.


## PIN screen fix
This version hard-locks the dashboard behind the PIN screen. The app content is not displayed or scrollable until the correct PIN is entered.
